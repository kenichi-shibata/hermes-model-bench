Fixed. The rating page was crashing with a `ZeroDivisionError`.

**Root cause:** `get_rating()` in `ratings_api.py` divides `total_score` by `vote_count`, but scenes 0–2 in `ratings_db.json` have `vote_count: 0` (no votes yet), so building the page data blew up on the very first scene.

**Fix:** Guard against zero votes — a scene with no votes now returns a rating of `0` instead of crashing:

```python
def get_rating(scene):
    if scene['vote_count'] == 0:
        return 0
    return scene['total_score'] / scene['vote_count']
```

Verified against the full DB: all 10 scenes now produce ratings (0 for unvoted scenes, 4.0 for the voted ones) with no errors.
