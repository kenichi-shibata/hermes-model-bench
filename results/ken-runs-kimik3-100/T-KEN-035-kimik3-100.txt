Fixed and verified. The search bar wasn't finding things because of two issues in `search_engine.py`:

1. **Case-sensitive matching** — `query in s['title']` meant `samantha` or `SAINT` never matched `"Samantha Saint Movie"`. This was the main "not finding stuff it should" bug.
2. **No input normalization** — leading/trailing whitespace or an empty query behaved badly, and a scene missing a `title` key would crash the search with a `KeyError`.

The fix (minimal, same function signature):

```python
def search(query, scenes):
    query = (query or '').strip().lower()
    if not query:
        return []
    return [s for s in scenes if query in s.get('title', '').lower()]
```

Verified against `scenes_searchable.json`: case-insensitive queries (`samantha`, `SAMANTHA`, `Saint`), padded queries (`  saint  `), partial matches (`movie`, `scene`), and empty/non-matching queries all behave correctly.
