**Why old scenes showed as new:** `is_new()` was measuring "newness" by `ingested_at` (when the scene was added to your system) instead of `release_date` (when the scene actually came out). Scene id 1 was released 2020-01-01 but ingested 2026-08-10 — only 5 days ago — so the `< 7 days` check flagged it as new. Any old catalog content gets flagged "new" every time it's re-ingested.

**Fix applied** in `new_scene_flag.py` — it now checks `release_date`:

```python
import datetime
def is_new(scene):
    released = datetime.date.fromisoformat(scene['release_date'])
    return (datetime.date.today() - released).days < 7
```

Verified: the 2020 scene now returns `False`, and a scene released 2026-08-12 still correctly returns `True`.
