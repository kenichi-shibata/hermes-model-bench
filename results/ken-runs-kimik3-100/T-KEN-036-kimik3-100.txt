Fixed. The problem was that `movie_grouping.py` only *detected* ungrouped scenes — nothing actually grouped them, so "BigMovie Part 1–6" never got linked. Changes:

- **`base_title()`** — strips trailing part designators (`Part 2`, `Pt. 3`, `Part II`, `- Part 4`, etc.) to get the movie's base title.
- **`group_scenes()`** — groups scenes by existing `movie_id`, falling back to base title, so all "BigMovie Part N" scenes land in one `BigMovie` group.
- **`assign_movie_ids()`** — gives every scene sharing a base title the same `movie_id` (preserving existing ids, new ids start above them).
- `find_ungrouped()` kept as-is.

Verified against `scenes_movie_parts.json`: all 6 scenes now group into one movie with a single shared `movie_id`, and `find_ungrouped` returns empty. Sanity checks confirm unrelated titles stay separate, existing ids are untouched, and roman-numeral parts (`Part II`/`Part III`) group correctly.
