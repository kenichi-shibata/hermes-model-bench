Fixed. The problem was in `similar_performers.py`:

**Root cause:** `vectors[str(performer_id)]` raised a `KeyError` for any performer without an entry in `performer_vectors.json` (the file notes "some performers missing vectors"), so the similar-performers lookup crashed instead of loading.

**Fix:** Use `.get()` and return an empty list when the performer has no vector:

```python
def get_similar(performer_id, vectors):
    v = vectors.get(str(performer_id))
    if v is None:
        return []  # performer has no vector; nothing to compare against
    return sorted(vectors.items(), key=lambda kv: sum((a-b)**2 for a,b in zip(v, kv[1])))[:5]
```

Verified: performer `0` (has a vector) returns its top-5 nearest performers as before, while performers `7` and `999` (missing vectors) now return `[]` instead of raising `KeyError`.
