**Root cause:** two things combine to produce scenes with no cover image.

1. **The data itself is incomplete.** In `scenes_covers.json`, scenes `0`–`4` have `"cover_url": null` — the field was never populated upstream (the other 15 scenes have a real URL).

2. **The resolver has no fallback.** `cover_image_resolver.py` is just:
   ```python
   def get_cover(scene):
       return scene.get('cover_url')
   ```
   It reads `cover_url` verbatim and returns it — so when the value is `null`, `get_cover()` returns `None` and the scene renders with no cover.

Notably, every one of those 5 scenes **does** have a `screenshots` array (e.g. `http://x/0_1.jpg`), so a cover *could* be derived — the resolver just never looks at it. The fix would be a fallback, e.g.:

```python
def get_cover(scene):
    return scene.get('cover_url') or (scene.get('screenshots') or [None])[0]
```
