Fixed. `get_studio()` in `studio_page_api.py` had dropped the `child_studios` field — the studio page's sub groups come from that field in `studio_hierarchy.json`, so they went missing.

The fix restores it:

```python
def get_studio(studio_id, studios):
    return {'id': studio_id, 'name': studios[studio_id]['name'],
            'child_studios': studios[studio_id].get('child_studios', [])}
```

Verified against `studio_hierarchy.json`:
- `parent1` → `{'id': 'parent1', 'name': 'MegaStudio', 'child_studios': ['child_a', 'child_b']}` ✓
- Studios without children safely return `child_studios: []` (via `.get(..., [])`) instead of raising `KeyError`.
