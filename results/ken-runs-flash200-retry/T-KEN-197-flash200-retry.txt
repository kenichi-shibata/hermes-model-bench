Usage:
- `python3 track.py record` — append current snapshot to history (UTC timestamped)
- `python3 track.py status` — current + latest snapshot + their diff
- `python3 track.py history` — list all snapshots
- `python3 track.py diff [N]` — diff current vs entry N (negative = from end)
