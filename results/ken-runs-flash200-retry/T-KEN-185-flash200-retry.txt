Gotcha: **mutable default argument**. `items=[]` is evaluated once at def-time, so subsequent calls without `items` reuse the same list.

- `add_item(1)` → `[1]`
- `add_item(2)` → `[1, 2]` (leaks state across calls)
- `add_item(3)` → `[1, 2, 3]`

Fix with `None` sentinel:

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```
