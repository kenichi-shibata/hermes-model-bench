**PR review**

- `file2_pagination.py:4` — **Blocking bug**: `offset = page * limit` is an off-by-one. `page=1` returns `items[limit:limit*2]`, skipping the first page. Should be `offset = (page - 1) * limit` (the docstring even says so).
- Same function: `limit` is never validated. `limit=0` or negative produces empty slices, and `page <= 0` yields undefined behavior — add a guard (`limit <= 0` / `page < 1`).
