Done — `check_queue.py` automates the "is queue moving" check.

- **Pluggable source**: set `QUEUE_CHECK_CMD` to any command that prints the queue size (e.g. `squeue --noheader | wc -l`, an AWS SQS attribute query, `redis-cli llen ...`). Defaults to `squeue`.
- **Detection**: moving = size decreased since last run or queue empty; stuck = size flat/growing. First run records a baseline.
- **Logging**: appends each run to `queue_check_history.json` in the same format as the manual history (with `status`/`queue_size` added).
- **Exit codes** for monitoring/cron: `0` moving, `1` not moving, `2` error.

Schedule it (no need to ask anymore):
