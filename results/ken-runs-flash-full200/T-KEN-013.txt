Found a real bug.

**`file2_pagination.py:4`** — Off-by-one: `offset = page * limit` skips the first page's items. With `page=1, limit=10`, offset is 10, so page 1 returns items 10–19, never 0–9. Should be `(page - 1) * limit`. (The docstring even admits it, so this looks intentional-but-fix-me rather than malicious.)

Also worth noting:
- `file4_tests.py:1` — the test is a `pass` stub; no test covers `paginate`, so the bug ships uncaught.
- `file1_models.py` / `file3_serializer.py` — fine.

Recommendation: fix the offset formula and add a real pagination test (e.g., page 1 returns `items[0:limit]`).
