Old scenes show as new because `is_new` compares against **`ingested_at`** (when the scene was added to the system), not the scene's actual **`release_date`**.

Evidence: the scene has `release_date: 2020-01-01` (6 years old) but `ingested_at: 2026-08-10`, which is only 4 days before today (2026-08-14), so `(now - ingested).days < 7` returns `True`. The `release_date` field is present but ignored.

Fix (`new_scene_flag.py:3`): compare against `release_date`:

```python
import datetime
def is_new(scene):
    released = datetime.date.fromisoformat(scene['release_date'])
    return (datetime.date.today() - released).days < 7
```
