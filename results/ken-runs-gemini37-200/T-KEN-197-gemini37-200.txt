Built a snapshot tracking system (`tracker.py` and `snapshot_tracker.py`) with a Python library and CLI to record, query, diff, analyze, and manage snapshots over time.

### Features
- **Automatic History Tracking**: Preserves and archives initial state, maintaining a timestamped log of snapshots in `history` while keeping `current` up to date.
- **Point-in-Time Queries**: Retrieve the active snapshot at any past timestamp (`get_snapshot_at`) or index (`get_snapshot_by_index`).
- **Diff & Trends**: Deep delta computation between snapshots and statistical trend extraction (min, max, avg, rate of change).
- **Rollback & Pruning**: Restore historical states and apply retention policies (by count or duration).
- **Export & Watch**: Export to JSON, JSONL, or CSV, with periodic sampling mode.

### Usage
```bash
# Record a new snapshot
python3 tracker.py record '{"metric": 48}'
python3 tracker.py record --metric 55 --note "load spike"

# Inspect current state and history
python3 tracker.py current
python3 tracker.py history

# Point-in-time lookup and diffing
python3 tracker.py at "2026-08-15T12:00:00Z"
python3 tracker.py diff -2 -1

# Metric trends and statistics
python3 tracker.py stats metric

# Rollback or prune
python3 tracker.py rollback 0
python3 tracker.py prune --keep 50

# Run full test suite
python3 -m unittest test_tracker.py
```
