In `pr_diff_3.py`, there is a **mutable default argument** gotcha:

- **Issue:** `items=[]` is evaluated once at function definition time. Calls relying on the default parameter share and mutate the same list instance across invocations.
- **Fix:** Use `None` as the default value and initialize the list inside the function:

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```
