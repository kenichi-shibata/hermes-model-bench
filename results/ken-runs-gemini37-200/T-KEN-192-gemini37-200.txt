### Added Capabilities
- **`export_to_csv(scenes, file=None)`** (aliases: `export_scenes_to_csv`, `export_csv`, `to_csv`): Exports single instances or iterables of `Scene` objects to a CSV file path, file-like object, or returns the CSV string if no file target is specified.
- **`Scene` Methods**:
  - `to_csv_row()`: Returns row data with flattened performers list (`[id, title, performers]`).
  - `to_dict()`: Returns a dictionary representation with flattened performers.
  - `to_csv(file=None)` / `export_to_csv(file=None)`: Exports the individual scene.
