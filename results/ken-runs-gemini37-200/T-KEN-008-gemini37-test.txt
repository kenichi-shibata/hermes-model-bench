### 1. Handling Multi-Part Movie Scenes in Stash
* **Grouping into a Stash "Group" (Movie):** 
  * Yes, Stash natively supports grouping multi-part scenes using the **Groups** (formerly "Movies") feature.
  * Create a Group (e.g., *MovieX*), link each scene part (IDs 100–105) to that Group, and set the **Scene Index** (1 through 6) to preserve chronological order.
* **Downloading Individual Parts vs. Full Movie:**
  * **Individual Parts:** Download each part as a separate file, import each as an individual scene, and link them under the same Group.
  * **Full Movie:** If you prefer a single file or parts are unavailable, you can download the entire movie as one release and import it as a single scene associated with the Group metadata.
