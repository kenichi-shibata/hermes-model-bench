The bug is in `new_scene_flag.py:3-4` — `is_new()` checks `ingested_at` (when the scene was added to the system) instead of `release_date` (when it was actually released). So a 2020 scene ingested on 2026-08-10 is wrongly "new" because it was recently ingested.

Fix:
`release_date` is a date-only string (`"2020-01-01"`), so `fromisoformat` handles it fine, and the 2020 scene will now correctly evaluate as old.
