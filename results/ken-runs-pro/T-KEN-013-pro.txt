**Review: this PR introduces an off-by-one bug in `file2_pagination.py`.**

`paginate()` computes `offset = page * limit` (file2_pagination.py:4). For `page=1`, this yields `items[limit:2*limit]`, skipping the first `limit` items entirely. Fix:

```python
offset = (page - 1) * limit
return items[offset:offset + limit]
```

Other notes:
- `file1_models.py`, `file3_serializer.py` look fine.
- `file4_tests.py:2` is a stub (`pass`) and won't catch this bug — a real test like `assert paginate([1,2,3], page=1, limit=2) == [1,2]` would have caught it. The serializer test should also assert actual output.
