The missing cover images were caused by scenes having `cover_url: null` without a fallback mechanism in `cover_image_resolver.py`.

Updated `get_cover` in `cover_image_resolver.py` to fall back to the first URL in `screenshots` when `cover_url` is absent or falsy:

```python
def get_cover(scene):
    cover = scene.get('cover_url')
    if cover:
        return cover
    screenshots = scene.get('screenshots') or []
    return screenshots[0] if screenshots else None
```
