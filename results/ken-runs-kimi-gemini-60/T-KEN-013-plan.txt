## The real problem

**Off-by-one in `pr_files/file2_pagination.py`, line 4:**

```python
offset = page * limit  # BUG: should be (page - 1) * limit
```

Assuming the conventional 1-indexed pages (confirmed by the docstring: "page=1 should return items[0:limit]"), the current code computes `offset = 1 * limit` for page 1, so page 1 **skips the first `limit` items** entirely, and every subsequent page is shifted by one page. Example with `items = [0..9]`, `limit = 3`:
- `paginate(items, 1, 3)` → returns `[3,4,5]`, should be `[0,1,2]`
- `paginate(items, 2, 3)` → returns `[6,7,8]`, should be `[3,4,5]`

The other three files are distractors; nothing else needs changing.
