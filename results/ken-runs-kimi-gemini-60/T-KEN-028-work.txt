The original implementation in `retry_engine_v2.py` was just spinning/counting without performing any actual retries or executing any work functions.

`retry_engine_v2.py` has been updated to:
- Accept an injectable callable `work_fn(item_id)` along with configurable `max_attempts` and optional `delay`.
- Execute `work_fn` in a loop up to `max_attempts` times with `try/except` handling.
- Record attempt counts and return execution status (`success` / `failed`), results, and error details.
- Provide a `reset(item_id=None)` helper to manage the attempts registry.
