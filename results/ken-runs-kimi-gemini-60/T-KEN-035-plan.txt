## Investigation findings

**The real problem: the search is case-sensitive.**

`search_engine.py` (the entire file, 2 lines):

```python
def search(query, scenes):
    return [s for s in scenes if query in s['title']]
```

`query in s['title']` is a case-sensitive substring match. Verified against `scenes_searchable.json` (2 scenes: `"Samantha Saint Movie"`, `"Other Scene"`):

| Query | Result | Expected |
|---|---|---|
| `"samantha"` | `[]` | should match scene 1 |
| `"Samantha"` | matches scene 1 | ✓ |
| `"movie"` | `[]` | should match scene 1 |
| `"Scene"` | matches scene 2 | ✓ |

So any query whose capitalization doesn't exactly match the title's capitalization silently returns nothing — that's why "the search bar isn't finding stuff it should."

**What is NOT the problem:**
- The data file is fine — it only has `id` and `title` fields, so searching `title` only is correct; there are no other fields (description, tags, etc.) being missed.
- No other code files exist; nothing else calls or wraps `search()`. `CONTEXT_ONLY.md` contains only the file listing, no extra requirements.
